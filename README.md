## The entry

> I finally cleaned out my fridge and found leftovers older than some of my friendships.

86 characters, one line, one everyday truth: the leftovers in the back of the fridge outlasted some friendships — a surprise at the end that still makes sense.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed line to `/output/entry.txt` — 86 characters, inside the 1–200 character gate. Deterministic, no network, no secrets, no randomness.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
